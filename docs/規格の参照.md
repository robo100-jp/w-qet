# JIS C 0617 をどう参照するか

記号を描き起こすには**規格の図を見る必要がある**。その入手方法の調査結果。
作業計画の「決まっていないこと #3」に対する答え。

## 前提：買って見る。写さない。

規格票は著作物で、**図版の複製・転載は禁止されている**（JSA の規格票にその旨の明記がある）。
このプロジェクトの方針は最初から変わらない。

- 規格を**参照して**、座標から**自分で描き起こす**
- 図記号番号は `<informations>` に参照として書く
- **「JIS準拠」とは名乗らない。**「JIS C 0617 を参考に作成」とする

規格を買って手元で見ること自体は当然できる。禁じられているのは図版の複製であって、
それを見て自分で描くことではない。

### 「JIS は税金で作られたから自由に公開できる」ではない

一度当たったので結論を残す。**成り立たない。**

JISC の[日本産業規格等に関する著作権の取扱方針](https://www.jisc.go.jp/jis-act/pdf/jis_copyright.pdf)
（令和2年11月30日改正）は、文書全体が **「JIS の著作権が誰に帰属するか」** を定めたもので、
JIS が著作物であることを前提にしている。

- **国費で作っても公有にならない。** 国が委託契約で原案を作らせた場合、
  産業技術力強化法第17条により「**第三者が…著作権者となることができる**」と明記
- 無償で公にすることが認められているのは列挙された範囲だけ。
  ①「官報公示及び**電子閲覧**に伴う…公表及び公衆送信を認める」
  ← JISC の無償閲覧はこの範囲。**公有だからではなく、個別に許諾された枠**
- ③ 出版及び公衆送信は「**適正な対価にて**」とされている。JSA が売っているのはこのため
- ⑦ 利用者が技術内容の一部を**社内規格等の一部として**使うことは認められる。
  ただし注記で「単にＪＩＳを社内規格に置き換える…場合は、ＪＩＳの複製に当たる可能性がある」

**C 0617 には、もう一段の権利がある。** これは IEC 60617 を採用した規格で、
JSA の和訳は IEC との取決めに基づいて出版されている。取扱方針の確認書様式にも、
原案が他の著作物を使う場合は原著作権者から「本文中の**図及び表**の…使用に係る
著作権使用許諾を取得」する欄がある。**図そのものに上流の権利が付いてくる。**

> 判例については探した範囲では見つからなかった。具体的な事件名・番号があれば読む。
> なお当方は法律家ではなく、これは実務上の risk 判断。最終的な判断は作者に委ねる。

### 結論：PDF を買う。記号を描くのが Claude Code だから

**これが選択を決める。** 記号の座標を起こすのは Claude Code なので、
**規格の図が機械から画像として読める形で手元に無いと作業にならない。**

そのため無償閲覧もハンドブックも、この用途には使えない。

| 手段 | なぜ使えないか |
|---|---|
| JISC 無償閲覧 | 登録に生年月日・住所・法人番号の入力が要り、**代理で登録できない**。閲覧のみの仕組みで、自動で読む使い方は想定外 |
| ハンドブック（冊子） | 紙。**PDF版が存在しない** |

**人が読むぶんには無償閲覧もハンドブックも良い。** 用途が違うだけ。

で **「PDFをバッグに入れる」** を選ぶ。**冊子と同額なので選び間違えに注意。**

| | 価格 | 判断 |
|---|---|---|
| **第7部 開閉装置・制御装置・保護装置**（204頁） | **¥17,600** | **買う。** 優先10記号のうち9個 |

**第1部は買わなくてよい。** 作図規則が入っていると踏んで調べたが、
第1部にあるのは **モジュール M＝5 mm** という基準寸法の定義までで、

## 網羅を前提にすると、最終的にいくら要るか

**電気設計でよく使う部品を網羅する**方針の場合の全体像。
価格は PDF・税込・すべて 2024 年版（令和6年12月20日改正）。
記号数は QET 同梱コレクションに収録されている数で、規格の収録数の目安。

| 1 | 概説・索引 | 176 | ¥8,250 | — | 索引のみ。**作図規則は無い** |
| **2** | **図記号要素，限定図記号** | 190 | **¥16,500** | 143 | **必須**（限時・手動操作・接地などの限定記号） |
| **3** | **導体及び接続部品** | 86 | **¥11,660** | 56 | **必須**（端子台・コネクタ・接地） |
| 4 | 基礎受動部品 | 62 | ¥10,780 | 49 | 中（CR・サージキラー） |
| 5 | 半導体及び電子管 | 200 | ¥17,600 | 153 | 中（ダイオード・SSR・整流器） |
| **6** | **電気エネルギーの発生及び変換** | 146 | **¥15,180** | 114 | **必須**（制御トランス・モーター） |
| **7** | **開閉装置，制御装置及び保護装置** | 204 | **¥17,600** | 161 | **最優先** |

**第2〜8部で ¥100,980。** 第1部を足すと ¥109,230。

### ハンドブックとの差が大きい

**新版JIS電気用図記号ハンドブックⅠ（¥8,800）に第1〜8部が全部入る。**
PDF で同じ範囲をそろえる ¥100,980 に対して **約12分の1**。

差は**冊子のみ・2011年版**であること、つまり **Claude Code が読めない**こと。
網羅を目指すと、この選択は「**機械が読める形にいくら払うか**」という問題になる。
差額 ¥92,180 がその対価。

### 買う順番は「網羅」ではなく「使う頻度」で

| 段階 | 買うもの | 追加 | 累計 | 何ができるか |
|---|---|---|---|---|
| **1** | 第7部 | ¥17,600 | ¥17,600 | 接点・コイル・タイマ・押しボタン・ブレーカ |
| **2** | 第2・3・8部 | ¥39,820 | **¥57,420** | 限定図記号・端子・導体・表示灯。**盤の主要部分がほぼ描ける** |
| 3 | 第6部 | ¥15,180 | ¥72,600 | 制御トランス・モーター |
| 4 | 第4・5部 | ¥28,380 | ¥100,980 | 受動部品・半導体まで網羅 |

**段階2 までで実務はほぼ回る見込み。**

あわせて**ハンドブック ¥8,800 を紙で持っておくと効率が良い。**
全体を見渡す・番号から引く・まだ買っていない部を確認する用途で、
どの部を PDF で買うか絞る判断材料になる。

### 規模の実感

第2〜8部で **742記号**ある。網羅とはこの規模で、ゼロから描き起こすと相当な作業量になり、
しかも大半は制御盤では一度も使わない。

実際に盤で使うのは **第7・2・3・8部に集中して 50〜80記号**というのが実感に近い
（手元の既存33記号もほぼこの範囲に収まっている）。

**まず第7部で1〜2記号を描いて、1記号あたりの手間を測る。**
742記号を追うのか50記号で足りるのかは、その数字が出てから決める。

> **利用条件。** 購入者名・会社名・注文番号・日付の**消せない透かし**が入る。
> 紙への複製は1部、バックアップ1部まで。**他の PC やサーバーへのコピーは不可。**
> 2台の PC で作業しているが、**PDF を両方に置くことはできない。**
> 記号を描く作業は片方の PC に寄せる。

> **版について。** 2024年改正版。ハンドブック（2011年）より新しい。

### 他国の無償公開も当たったが、同じ壁で止まる

「どこかの国が同じ IEC 60617 を採用した規格を無償公開していないか」は筋の良い発想で、
実際に有力な候補がある。**中国の[国家标准全文公开](https://openstd.samr.gov.cn/bzgk/std/)**
（国家市場監督管理総局）は多くの GB 規格を**全文無償**で公開していて、
**GB/T 4728 が IEC 60617 の採用規格**（番号体系も同じ）。

だが、必要な部だけ**除外されている。**

| | |
|---|---|
| GB/T 4728.7-2022（開閉・制御・保護器件） | 「由于涉及版权保护问题，本系统不提供文本阅读服务」 |
| GB/T 4728.8-2022（計器・ランプ・信号装置） | 同上 |

**理由も明記されている** — 「该标准采用了ISO、IEC等国际国外组织的标准」。
**IEC を採用しているから全文公開の対象外。** 日本固有の事情ではなく、
どの国の採用規格を当たっても同じ IEC の層で止まる。

> GB/T 4728 の PDF を掲げるサイトがいくつか見つかるが、**権利者が公開したものではない**
> ため使わない。公開リポジトリの土台を、出所を説明できないものに置くわけにいかない。

### 買う前にできること

優先10記号の最初のいくつか（a接点・b接点・リレーコイル）は、
**制御盤の実務者なら形が頭に入っている。** 番号は作業計画に控えてある。

口頭で形と寸法を指示してもらえれば、規格票が届く前に描き起こして
[寸法基準](寸法基準.md)の検証まで進められる。規格票はその**答え合わせ**に使う、
という順番も取れる。ただし**最終的には規格を見て確かめる必要がある。**

## QET 同梱コレクションを索引に使うか

**この調べをした時点の同梱には `91_en_60617`（IEC 60617 の番号でフォルダ分け）があった。**
0.100.0 の手元の同梱には無く、`10_electric` ほか5つに変わっている。

```
en_60617_07/en_60617_07_02/en_60617_07_02_01.elmt   ← 07-02-01
```

部ごとの記号数は 第2部143／第3部56／第4部49／第5部153／第6部114／
**第7部161**／第8部66／第11部170。優先10記号の番号はすべて存在する。

つまり**「どの番号が存在するか」の一覧としては、当時はただで手元にあった。
いまの 0.100.0 には無い**ので、この手は使えない。

**あったとしても、これに寄りかからない。**

- 番号体系は IEC/JIS のものであって QET のものではないので、番号の羅列自体は事実に近い。
  ただし**採録一覧を彼らのフォルダ構成から起こすのは、彼らのコレクションから索引を派生させること**になる
- 名称は彼らの訳語であって、規格の用語とは限らない
- **ハンドブックを買えば番号索引が付いてくるので、そもそも要らない**

番号が実在するかの当たりを付ける程度に留め、**採録一覧は規格側から起こす。**

## 買った PDF の置き場所

**リポジトリに入れない。** ここは公開リポジトリなので、
買った規格票やそれを描き出した画像を置くと**著作物を再配布することになる。**

`.gitignore` で `*.pdf` と `規格/` `参照/` を除外してある。事故を防ぐための多重化であって、
そもそも置かないこと。**リポジトリの外**（例：`C:\規格\` や OneDrive の外の作業フォルダ）に置き、
絶対パスで参照する。

## 規格の図を読む

`tools/pdf_page.py` でページを画像に描き出す。テキスト抽出では図が取れないので、
ページを丸ごとラスタライズする。

```bash
py -3 tools/pdf_page.py "C:\規格\JIS C 0617-7-2024.pdf" --search "07-02"
```

図記号番号でページを探してから、そのページを描き出す。

```bash
py -3 tools/pdf_page.py "C:\規格\JIS C 0617-7-2024.pdf" 42-43
```

**出力先はリポジトリの外**（`%TEMP%\w-qet-pdf\`）が既定。これも事故を防ぐため。
細かい図は `--dpi 300` に上げる。

## 規格から採った情報を、どこに落とすか

**規格票 PDF は家PCにしかない。**会社PCでも作業できるように、
規格から読み取ったものは**リポジトリの中のテキスト**に落としてある。

| ファイル | 中身 | 誰が作るか |
|---|---|---|
| `docs/規格データ/第<N>部索引.tsv` | 図記号番号 → 節・分類・ページ・名称 | **機械**（`mkindex.py`。手で触らない） |
| `docs/規格データ/第<N>部注釈.tsv` | 注釈の**要点をこちらの言葉で** | **手** |
| `docs/規格データ/第<N>部注釈_適用.tsv` | 注釈 → 付いている図記号 | **機械**（規格票から抜く） |
| 各 `.elmt` の `<informations>` | その記号だけの制約 | **手** |

> **3つに分けてあるのは、作り直しの主体が違うから。**
> 索引と適用先は規格票から作り直せる（作り直すたびに丸ごと上書きする）。
> 要点は手で書いたもので、**混ぜると作り直しで消える。**
> `docs/sym/*.html` の手書き欄を索引に混ぜないのと同じ理由。

> **どれも規格票の本文を写したものではない。**番号・分類・ページのような事実と、
> 要点を自分の言葉で書き直したものだけ。原文が要るときは番号で規格票を引く。

これがあるので `sympage.py`（`docs/sym/` を作る）は **PDF を要らない。**

## 進め方

1. **その部の PDF を買う**（第7部 ¥17,600・第8部 ¥11,660・第6部 ¥15,180）。
   リポジトリの外に置く
2. `py -3 tools/mkindex.py --part <N> --write` で索引を作る。**手で作らない**
   （出力は `docs/規格データ/`。文書ではなく作業用のデータなので分けてある）
3. 注釈を読んで `docs/規格データ/第<N>部注釈.tsv` に要点を落とす
4. 規格の図を見て[寸法基準](寸法基準.md)に沿って描き起こす
5. 描いたら必ず目視する

```bash
py -3 tools/render_elmt.py 07-02-01
```

手順の全体は `.claude/skills/jis-symbol/SKILL.md` の
「新しい部を買ったときの手順」に8段階で書いてある。
