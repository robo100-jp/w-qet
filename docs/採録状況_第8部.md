## 中断したときの再開手順

```bash
py -3 tools/status.py --next 10   # 次に描くものと規格票のページ
```

1. 上のコマンドで次の番号と**規格票のページ**を出す
2. `py -3 tools/pdf_page.py "<規格票>" <ページ> --dpi 600` で図を描き出す
3. ドット格子（**1M = 10**）を基準に座標を読み、`.elmt` を起こす
   置き場所は `elements/JIS_C_0617/<節>/<番号>_<和名>.elmt`
4. `py -3 tools/render_elmt.py <名前>` で**必ず目視**
5. `py -3 tools/status.py` でこの文書を作り直し、コミット

規格票の在りかと寸法の約束は [規格の参照.md](規格の参照.md) と[寸法基準.md](寸法基準.md)。
