## 描き起こしの手順

```bash
py -3 tools/pdf_page.py "<規格票のパス>" --search "07-02"   # ページを特定
py -3 tools/pdf_page.py "<規格票のパス>" 20 --dpi 600        # 図を描き出す
```

規格の図には**ドット格子が添えられている。これが作図モジュール M** で、
**1M = 10**（実測で確認済み。[寸法基準.md](寸法基準.md)）。
格子を基準に座標を読み、`.elmt` を起こす。

描いたら**必ず**画像にして目視する。

```bash
py -3 tools/render_elmt.py 30_a接点
```

> **規格票はリポジトリに入れない。** 描き出した画像も同様。
> `pdf_page.py` の出力先はリポジトリの外が既定。
