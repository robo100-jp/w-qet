**規格に基づく図記号ではない。**フォリオ参照は図面作成の規約で、IEC 60617（図記号）ではなく IEC 61082（図面の作成）の領域。 作図の都合で置いている部品。 前のページから来た導体の続きを示す。参照先は QET が札の中に書き込む。 使う前に**プロジェクトの属性 →「新しいフォリオ」→「フォリオ参照のラベル」を `%id-%l%c` にする**（`%f` は空になることがある）。 **この設定は新しく作るフォリオにしか効かない。既存のフォリオには反映されない。** そのうえで相手の札とリンクする（右クリック →「リンクする要素」→ 相手をクリック）。 導体の線番は関係ない。

一般的な名称手で書く欄

この図記号が指す部品を、ふだん何と呼ぶか。現場・部品表・カタログでの言い方。規格の名称とは別。規格が「安全開離機能接点」でも、通じるのは「ミラー接点」。探すときはこの言葉で探すので、目次の絞り込みもここを見る。
名前だけを書く。どういう部品かの説明は次の欄へ。ここは .elmt の名称（QET の部品パネルに出る名前）の元になる。

この図記号から何を作るか手で書く欄

CAD用シンボルにする／しない

CAD 用のシンボル（QET の .elmt、DXF のブロックなど）を作るかどうか。「しない」と書いてあれば作らなくてよい。図（SVG）とこの頁は、作らないものにも用意する。
「する。」か「しない。」で書き始めること。道具がそこだけ見て数える。規格票から判断が付くときも、人が決めるときも、書く場所はここ。

する。

組合せ・変種

この図記号から派生させて作ったもの、これから作るもの。組合せ（他の番号と組んだもの）と変種（規格に無い色・段数・向きなどを足したもの）の両方をここに書く。作った先のファイル名も書いておくと、頁から頁へたどれる。

（組合せの例：07-07-02（押しボタンの操作子）＋ 07-07-07（ブレーク接点） → 07-07-02_07-07-07　／　変種の例：色ちがい → 08-10-01__green）

他の形式に写すときの約束

  • 1単位 = 0.1M = 0.5mm。規格の作図モジュールは M = 5mm
  • 原点は挿入基点、y は下向き。JSON の座標はすべて原点基準。y が上向きの CAD（DXF など）に写すときは y を反転する
  • 弧の角度は 3時方向が0度、反時計回りが正。SVG は逆向き。DXF の ARC は反時計回り正で同じ向きだが、終了角で指定するので 開始 + 角度 を渡す
  • 円・楕円・長方形は軸平行のみ。傾いたものは表せない
  • 線の太さは 細 / 標準 / 太 の3段階。規格票の線は実測 0.10M ≒ 0.5mm
  • 破線の刻みは指定できない（Qt のペンそのまま 4:2）。規格票の刻みは 1.0M で、こちらは 0.6M
  • 文字は 1em = pt × 96/72 単位。書体は Liberation Sans（≒ Arial）。規格票はセリフ斜体だが、書体は合わせないと決めてある
