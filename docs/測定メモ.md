## いま控えているもの —— 第7部の旧図記号

第7部は索引を作り直して 180個と分かり、**19個が未採録**（すべて附属書A）。
そのうち2個を測ったので控える。

### 07-A12-01 複合スイッチ（一般図記号）（p.197）　墨 10.08×8.10M

外枠 10.0×8.0M の中に線だけ。**引出し線が無い。**

    外枠      x 0.05〜10.05、y 0.05〜8.05
    縦線      x=3.05。y1.51〜3.09 と y3.51〜5.10 の2本（間が 0.42M あく）
    横線      y=4.55。x2.05〜8.05
    左の縦線  x=2.05。y4.55〜6.60（横線の左端から下へ折れる）

原点を外枠の中心に置くと、縦線は x=-20、左の縦線は x=-30、横線は y=+5。
端子は外枠の縁に足すことになる（3本の線の行き先＝上・下・右）。

### 07-A13-01 スイッチ（p.200）　墨 8.69×6.09M

**規格票は図を2つ並べている**（左＝支点の小円なし、右＝あり。注釈 A00060）。
左を採る。形は 07-02-01 と同じだが**刃の角度が違う。**

    上の縦線  x=1.36。y0.00〜2.05
    刃        (0.05, 1.80) → (1.36, 4.00)　dx 1.31・dy 2.20
    下の縦線  x=1.36。y4.00〜6.09

原点を軸と中心に置くと、刃は (-13, -12.5) → (0, 10)。
07-02-01 の刃は (-10,-10)→(0,10) なので、**上に 0.25M 長く、左に 0.3M 広い。**
