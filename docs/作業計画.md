## 目標

**電気設計でよく使う部品を網羅的にそろえる。**

ただし**買う順番・描く順番は「網羅」ではなく「使う頻度」で決める。**
JIS C 0617 の第2〜8部には 742記号あるが、制御盤で実際に使うのは
**第7・2・3・8部に集中して 50〜80記号**と見込まれる（手元の既存33記号もこの範囲）。

規格票の購入も段階を踏む。全部そろえると ¥100,980、実務が回る段階2までで ¥57,420。
内訳は [規格の参照.md](規格の参照.md) の「網羅を前提にすると、最終的にいくら要るか」。

**まず第7部で1〜2記号を描いて、1記号あたりの手間を測る。**
742記号を追うのか50記号で足りるのかは、その数字が出てから決める。

## 最初にやること

### 1. 描き起こしの方式を決める ✔ 済

**案A（Python で座標から `.elmt` を生成）。** 以前の案件と同じ。
`render_elmt.py` で目視確認を回せるので、形の誤りは拾える。

### 2. 寸法の基準を決める ✔ 済

→ [寸法基準.md](寸法基準.md)。要点だけ。

- グリッド 10。`width`/`height` は10の倍数
- 端子間は**縦置き機器 60**（`y = ±30`）／端子・ジャンクション 30
- `hotspot_x = width/2`、`hotspot_y = height/2`。端子は原点対称
- ラベルは `x = width/2 + 5`、`y = -height/2`、`keep_visual_rotation="true"`
- `<terminal>` に `uuid` `name` `type="Generic"` は必須

### 2.5 規格を読めるようにする ✔ 済

**JIS C 0617-7:2024 の PDF（¥17,600）を買う。** → [規格の参照.md](規格の参照.md)

[JSA Webdesk](https://webdesk.jsa.or.jp/books/W11M0090/index/?bunsyo_id=JIS+C+0617-7:2024)
で **「PDFをバッグに入れる」**（冊子と同額なので選び間違えに注意）。

**記号を描くのは Claude Code** なので、規格の図が**画像として機械から読める形**で
手元に無いと作業にならない。無償閲覧（代理登録できない）もハンドブック（PDF版が無い）も
この用途には使えない。第1部は作図規則を含まないので不要。

届いたら次の手順で進む。

1. **リポジトリの外**に置く（例 `C:\規格\`）。`.gitignore` で `*.pdf` を除外済みだが、
   そもそも入れない。公開リポジトリなので再配布になる
2. `py -3 tools/pdf_page.py "<PDFのパス>" --search "07-02"` でページを特定
3. そのページを描き出して図を見る → [寸法基準.md](寸法基準.md) に沿って座標を起こす
4. `py -3 tools/render_elmt.py <名前>` で目視

**PDF は他PCへのコピー不可**（透かし入り）。記号を描く作業は片方の PC に寄せる。
