# 制御盤 改造案件の進め方

新規設計ではなく**既存盤に手を入れる**案件の段取り。
改造は「触る既存配線の本数」がそのまま工数になるので、**変更を最小に抑えることが設計の目的**になる。

## 大原則

> **既存に触る量を数えられる状態にしてから、部品を選ぶ。**

順序を逆にすると、部品が決まってから「その配線は届かない」「端子が足りない」が出て手戻りする。

---

## 手順

### 1. 原資料をそろえる

最低限この2つ。**両方そろって初めて解読できる。**

| 資料 | 役割 |
|---|---|
| **回路図（展開接続図）** | 動作の論理。何がどういう順で動くか |
| **配線箇所・長さ一覧表（配線表）** | 物理の実体。どの機器のどの端子から、何色の線が、どこへ |

ほかに機器一覧表（型式・価格）、機器配置図、穴加工図があれば入手する。
**機器一覧表に購入画面が添付されていることがあり、その場合は見積根拠として直接使える。**

### 2. 配線表を全行データ化する

**これが最重要資産になる。** スキャンPDFなら手で転記してでもデータにする。

```
No / 電線色 / 線番 / 機器1 / 端子1 / 線番 / 機器2 / 端子2 / 経路 / 長さ / ねじ
```

転記したら**行数を原資料と突き合わせる**。空行やページ跨ぎの重複がよくある。

### 3. 回路図と配線表を突き合わせて解読する

回路図だけでは「同一電位に複数の番号が付く」理由が分からない。
配線表の**ショート線**を見ると、それが端子台の短絡群だと分かる。

解読でよく出てくる罠。

- **電磁開閉器の主接点と操作コイルが同じ端子番号**で書かれている → 配線色で判別する（動力＝白/黒、制御＝赤）
- 配線表に**同一内容の行が重複**している → 原典の誤記の可能性。製作前に要確認
- **欠番**がある → 実際に使っていないだけのことが多い

### 4. 図面を起こしたら、配線表と機械照合する

**目視でなく機械で突き合わせる。** ここで転記ミスや描き落としが出る。

```
図面から抽出した端子番号の集合  vs  配線表の端子番号の集合
```

差分は必ず全部説明できること。説明のつかない差分が残っているうちは完成していない。

> 実例：この照合で「端子〔6〕が図面に無い」を発見した。短絡群の一員で電気的には等価だが、
> 端子台表を出すと端子が1つ足りなくなる。原因は生成スクリプトの転記ミスだった。

### 5. 既存に加える変更の全量を洗い出す

**見積の工数根拠になるので、独立した節として文書化する。**

| 区分 | 数えるもの |
|---|---|
| 触る既存配線 | 何番の配線か。**端末の付け替えだけか、電線の引き直しが要るか** |
| 新設する配線 | 区間と本数 |
| 端子台 | 新たに使う端子。既存の空きで足りるか |
| 変わらないもの | 残りの配線本数、動作シーケンス、機器の物理配置 |

### 6. 変更を減らせないか検討する

**「移設」と書かれていても、電気的には配線の付け替えだけで済むことがある。**

移設先の端子が同じ端子台の中なら、既存電線がそのまま届く。
機器を物理的に動かすと、取付穴の追加加工・電線の引き直し・ダクト経路の変更まで発生する。
**この差は工数で数倍になる。**

配線表から移設元と移設先の端子・電線長を引いて、届くかどうかを確認する。

## 部品選定の勘所（日本の制御盤）

### 最小適用負荷

**微小電流でスイッチ接点を使うと、接点表面の酸化皮膜で接触不良を起こす。**

- 一般負荷形（銀接点）のスイッチは**最小適用負荷 160mA 程度**を要求されることが多い
- リレーコイルだけを駆動すると数十mAしか流れず、これを下回る
- 対策は**ブリーダ抵抗をコイルと並列**に入れて電流を底上げする

**接点を直列にする構成では、接触不良のリスクが接点数に比例する。** 4個直列なら4倍。

温度の影響も見る。**コイルは銅線なので温度が上がると抵抗が増え、電流が減る**（0.393%/K）。
常温で足りていても、夏の盤内温度で下回ることがある。

> 金クラッド接点なら微小負荷に対応するのでブリーダ抵抗は不要。ただし部品単価は上がる。

### 電線の耐候性

| 種別 | 屋外 |
|---|---|
| VCTF / VCT（ビニルキャブタイヤ） | **不可。** 耐候性（耐紫外線）が弱い |
| 2PNCT 等（ゴムキャブタイヤ） | 可 |

やむを得ずビニル系を屋外に使うなら、**可とう管・スパイラルで保護する**か日射を避ける経路にする。

### 端子台の適合電線

**電流だけで細くしない。** 端子台には適合電線の下限がある（例：0.75〜2mm²）。
容量的に足りても、下限を割ると端子が電線を保持できない。

### 保護等級

- 箱の等級が系全体の弱点になる。スイッチが IP67 でも箱が IPX3 なら意味がない
- **地面に近い位置は泥はね・跳ね返りを受ける**ので、上部の盤より高い等級が要る
- 電線の引込口は**必ず防水グランドで塞ぐ**。1本につき1個

### 調達

- **メーカーが標準価格を公開しなくなっている**ことがある。販売店見積が前提
- **型式が生産終了していることがある。** 推奨代替品にはピン配置や端子ねじが変わるものもある
- 価格は改定される。**過去の調査値をそのまま見積に使わない**

## 帳票と納品

### 配線表は「表」で出す

現場は表を見て配線する。ハーネス図の類は、コネクタ間を線束でつなぐ構造の機器向けで、
**端子台中心の放射状配線である制御盤とは構造が合わない。**

原資料と同じ列構成で出せば、施工側は何も覚え直さなくて済む。

### CSV を Excel で開くと値が壊れる

| 値 | Excelで開いた結果 |
|---|---|
| `+V(DC12V)` | **`#NAME?`**（先頭の `+` を数式と解釈） |
| `9-5`（接点表記） | **日付に変換** |
| `007` | `7`（先頭ゼロ消失） |

対策。

- **納品物は xlsx で作る**（全セルを文字列書式にする）。罫線・列幅・印刷設定も持てる
- CSV を使うなら **Power Query で取り込み、「変更された型」を削除する**
- 文字コードは `utf-8-sig`（BOM付き）にしないと文字化けする

### 呼称のゆれは型式で吸収する

「ケーブルクランプ」には防水機能のないサドル類も含まれる。
**品名がどうであれ、型式欄に `PG13.5 IP67` のように書けば誤発注は起きない。**

## 文書の残し方

改造案件は期間が空くことが多い。**なぜそうなっているかを追える形で残す。**

- **判断の履歴** — 不採用にした案とその理由。後から「なぜこれを選ばなかったか」を聞かれる
- **未決事項の一覧** — 誰に何を確認すれば決まるのかを明記する
- **設計上の申し送り** — 省略してはいけないもの、間違えやすいもの

現地確認は1回の訪問でまとめて済ませられるよう、**チェックリストの形にしておく。**
