# w-qet

QElectroTech 用の、日本の制御盤向け図記号ライブラリと作図ツール。

制御盤の改造案件で QElectroTech を実用に載せる過程で必要になったものを、案件から切り離してまとめている。

> **これは QElectroTech 公式のプロジェクトではありません。**

> 作者の勤務先とは関係のない、個人のリポジトリです。
> 内容の正しさは保証しません。実務で使う場合はご自身で確認してください。

## 構成

```
elements/      .elmt 図記号定義
tools/         Python ツール
  paths.py       図記号の在りかを解決する（他が使う）
  elmtgen.py     .elmt を座標から組み立てるライブラリ
  qetgen.py      .qet をコードから生成するライブラリ
  render_elmt.py .elmt を PNG に描き出す（目視確認用）
  check_elmt.py  .elmt を検証する（外形・端子・属性。目視では出ない誤り）
  check_qet.py   .qet を検証する（重なり・はみ出し・端子未指定・相互参照・線番）
  stdpage.py      規格票のページから図の帯と格子を取り出す
  compare_page.py 描いた記号を規格票と突き合わせる
  pdf_page.py    PDF のページを画像に描き出す（規格の図を読む）
  status.py      採録状況を elements/ から数え直す
  svg_elmt.py    .elmt を SVG に写す（人に見せる姿）
  catalog.py     カタログ（docs/カタログ.md と docs/images/）を作り直す
  cheatsheet.py  印刷用の早見表（docs/チートシート.svg）を作る
  install.py     図記号を QET のユーザーコレクションに登録する
docs/          設計方針・採録状況・カタログ
.claude/skills/  Claude Code 用スキル
```

- 記号の姿を見る … [docs/カタログ.md](docs/カタログ.md)・[docs/チートシート.svg](docs/チートシート.svg)
- 次に何をするか（作業の引継ぎ） … [引継ぎ.md](引継ぎ.md)
- 採録状況（図記号番号と名称の一覧） … [docs/採録状況.md](docs/採録状況.md)
- 記号の寸法・端子・ラベルの約束ごと … [docs/寸法基準.md](docs/寸法基準.md)
- 規格票を測ったが、まだ描いていないものの控え … [docs/測定メモ.md](docs/測定メモ.md)
- ツールの使い方と `.elmt` の書式 … [docs/ツール.md](docs/ツール.md)

> **カタログとチートシートは手で書きません。** `py -3 tools/catalog.py` と
> `py -3 tools/cheatsheet.py` が `elements/` から作り直します。

## QET に登録する

```bash
py -3 tools/install.py
```

取り除くとき。**フォルダ構成が変わったときは、入れる前にこれを叩いてください**
（古い名前のフォルダが残って二重に並びます）。

```bash
py -3 tools/install.py --uninstall
```

`%APPDATA%\qelectrotech\QElectroTech\elements\w-qet\` に入ります。
**既存の部品とは混ざりません。**

QET の部品パネルにはこう並びます。

```
電気用図記号（日本）
├─ JIS C 0617        規格を参照して描き起こしたもの
│   ├─ 07-02 接点
│   ├─ …
│   └─ 07-A 旧図記号（参考・使わない）
└─ 作図用部品          規格に無い、作図の都合のもの（端子・ジャンクション）
```

> 上はQETの部品パネルでの**表示名**です。フォルダの実名は `07-02` `drawing_aids` の
> ようにASCIIで、表示名は各フォルダの `qet_directory` が持っています。
> **日本語のフォルダ名にすると QET がその `qet_directory` を読めません。**

> `07-A` は規格の附属書A に載っている**既に削除された図記号**です。
> 古い図面を読むための参考で、新しく描く図面には使いません。

登録後は **QET を再起動**してください（起動時にコレクションを読むため）。
QET はスタートメニューから起動します。exe を直接叩くと部品が0個になります。

## なぜ作るか

QElectroTech は同梱の `91_en_60617` に IEC 60617 の規格記号を約900種持っているが、

- **約63%の部品が端子を持たない。** 規格のリファレンス集であって作図用ではなく、置いても導体がつながらない
- 名称が英語・フランス語で、日本語名が無い
- 日本の制御盤で使う記号（電磁開閉器の主接点、限時接点、押しボタン等）が探しにくい

ここを埋めて、**日本語名がついていて、端子を持っていて、そのまま作図に使える**記号集にする。

## 図記号は自分で描き起こす

同梱コレクションから派生させると、`ELEMENTS.LICENSE` により**回路図の外での再配布は CC-BY** の条件に従うことになる。
帰属表示（`Author: The QElectroTech team`）を保つ義務が生じ、ライセンスを自由に選べない。

このプロジェクトでは**上流から派生させず、JIS C 0617（＝IEC 60617）を参考に座標から描き起こす。**
図記号番号は参照として記載するが、規格書の図版を複製するものではない。

> 「JIS準拠」とは名乗らない。適合宣言と受け取られうるため、「JIS C 0617 を参考に作成」とする。

**描いたら必ず `render_elmt.py` で画像に描き出して目視すること。** 座標だけでは形の誤りに気づけない。
